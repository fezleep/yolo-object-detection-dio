# Texto para entrega da DIO

Projeto de detecção de objetos com YOLOv8 e Ultralytics, usando um modelo pré-treinado para executar inferência em imagem e gerar um resultado visual com bounding boxes.

O repositório inclui um notebook para rodar no Google Colab, um script local em Python e uma organização básica de pastas para imagens, código, dataset e documentação.

A demonstração prática usa pesos pré-treinados, então não afirmo que houve treinamento customizado do zero. O projeto também documenta o caminho para evoluir a solução com transfer learning, preparando uma base anotada no formato YOLO e treinando novas classes a partir do modelo pré-treinado.
